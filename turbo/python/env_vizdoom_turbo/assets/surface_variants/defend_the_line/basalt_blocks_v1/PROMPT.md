# Basalt Blocks v1

Generation mode: built-in imagegen

## Prompt

Create one original seamless square tileable game texture for a Doom-compatible reinforcement-learning environment. Asset type: front-facing orthographic wall material. Subject: dark basalt masonry blocks with varied block sizes, charcoal and cool gray stone, restrained ember-orange mineral seams and a few subtle pitted chips. Composition: a uniform repeating material with no focal point; opposite left/right and top/bottom edges must join seamlessly. Style: crisp low-resolution 1990s first-person-shooter pixel art, hard pixel clusters, limited readable palette, strong material definition, designed to survive nearest-neighbor downscaling to exactly 64x64 pixels. Lighting: flat neutral material lighting, no directional cast shadows and no overall gradient. Exclude characters, creatures, weapons, scenery, perspective, depth corridors, text, logos, watermarks, UI, borders, frames, and recognizable copyrighted designs. Make the texture fully opaque.
