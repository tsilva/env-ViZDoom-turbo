# Dark Stone v1

Generation mode: built-in imagegen

## Prompt

Create one original seamless square tileable game texture for a Doom-compatible reinforcement-learning environment. Asset type: top-down orthographic floor material. Subject: dark charcoal stone floor slabs, irregular but walkable, with subtle cool-gray grain, worn joints, and sparse desaturated moss-green flecks; visually quiet enough that enemies remain readable. Composition: a uniform repeating planar material with no focal point; opposite left/right and top/bottom edges must join seamlessly. Style: crisp low-resolution 1990s first-person-shooter pixel art, hard pixel clusters, limited readable palette, designed to survive nearest-neighbor downscaling to exactly 64x64 pixels. Lighting: flat neutral material lighting, no directional cast shadows, no highlights implying a viewpoint, and no overall gradient. Exclude characters, creatures, weapons, scenery, perspective, holes, stairs, objects, text, logos, watermarks, UI, borders, frames, and recognizable copyrighted designs. Make the texture fully opaque.
